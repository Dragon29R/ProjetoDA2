\doxysubsection{Detailed Description}
Represents an station. 

The \doxylink{class_vertex}{Vertex} class represents a station in a graph, with its ID, adjacent edges, visited status, processing status, indegree, distance, path, incoming edges, name, district, municipality, township, and train line.
